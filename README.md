Car Price Prediction using Machine Learning

This project is all about predicting the **price of a car** based on its features. The dataset contains information such as year, mileage, fuel type, engine size, and other relevant details.  

The goal of this project is to explore the data, perform feature engineering, and build regression models that can accurately predict car prices.
 Project Goals
- Understand and clean the dataset  
- Perform **Exploratory Data Analysis (EDA)** to identify patterns and relationships  
- Encode categorical variables and scale features if necessary  
- Train and evaluate multiple regression models such as:
  - Linear Regression  
  - Random Forest Regressor  
  - Decision Tree Regressor  
- Compare model performance using **RMSE, MAE, and R²**
